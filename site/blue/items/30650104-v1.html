[Kaivax] Overly Restrictive Name Check and Fix Incoming - October 27

2026年10月28日 · 在暴雪论坛查看原帖

Kaivax（Community Manager） 回复于第 1 楼

In WoW Forever, we’ve been working on the restricted name list, which is a list the game uses to check for non-profane names that we wish to restrict, such as major Warcraft lore characters or names that are blocked for technical reasons.

Today we’ve determined that we have a bug in the process that caused the game to be overly restrictive with some names. For example, it has been incorrectly restricting names containing “c-o-n”.

With the next realm restarts in each region, we’re going to implement the fix. Afterward, if you previously received a message that said “That name is restricted” for a name that you think should have been allowed, please feel free to try again.

Thank you!
